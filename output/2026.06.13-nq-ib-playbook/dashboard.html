this is a reactive setup — do not anticipate. wait for the failure confirmation before entering.

phase 1
after 10:30, IBH (or IBL) breaks with initial momentum — looks like setup B at first.
failure signal
within 1–4 candles (5-min), price closes back inside the IB. for a failed IBH break: 5-min close back below IBH. volume dries up on the move above IBH = additional tell.
entry
short on the 5-min close back below IBH (failed breakout case). ES must also be failing back below its IBH — if ES is holding, skip.
stop
above IBH + 50 pts — tight. the whole thesis is invalidated if price gets back above IBH with conviction.
T1 — IBL
IBL (350 pts below IBH) — the full IB range. take 50% off at IBL.

IBL minus 88 pts (L1) — once IBL breaks on the reversion, the same 72% L1 rule applies. hold 50% for L1 below IBL.
R:R
risk 50 pts → T1 at 350 pts (7:1). this is why setup C is the highest R:R despite only occurring 14% of sessions — tight stop, huge range to target.

pre-trade checklist — run this at 10:30 every session

step 1 — identify IB formation (9:30–10:30)
did IBL form before IBH? (bearish opening move) → setup A signal active (81%)
did IBH form before IBL? (bullish opening move) → setup A short signal (63%)
is ES showing the same formation sequence? → confirms signal. diverging ES = reduce size or skip.
is today tuesday? → double-break rate 23%, require ES confirmation for any setup B trade.
step 2 — act at or after 10:30
IBL formed first AND price is now pushing toward IBH → long near current level, stop below IBL, T1 = IBH. setup A.
IBL breaks after 10:30, ES also breaking → short, stop above IBL, T1 = L1 (88 pts below IBL). setup B1.
ES breaks IBH, NQ still at IB level → long NQ at IBH pullback, stop below IBH, T1 = L1 (88 pts above IBH). setup B2.
IBH (or IBL) breaks then immediately fails back inside IB, ES also failing → fade the failure in the opposite direction. setup C.
